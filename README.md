# EngiX (Flutter، نیتیو)

## اجرا روی کامپیوتر (Flutter SDK نصب باشد)
    bash setup.sh          # فقط بار اول (ویندوز: داخل Git Bash)
    flutter run            # اجرا روی گوشی/شبیه‌ساز
    flutter build apk --release

## بدون نصب چیزی
پروژه را در گیت‌هاب پوش کن و از تب Actions ورک‌فلو «Build Flutter Android» را اجرا کن.
فایل APK در بخش Artifacts می‌آید.

## مرحله ۱ شامل
- ورود با OTP موبایل و ایمیل (همان API های Vercel)
- ذخیره‌ی نشست با Supabase
- تکمیل پروفایل و نقش‌ها
- قالب اصلی اپ با ۵ تب (هنوز خالی)
